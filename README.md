# Pitucos Café

Site estático pronto para hospedagem no GitHub Pages. Não precisa instalar dependências nem executar build.

## Arquivos

- index.html: página principal
- styles.css: aparência e adaptação ao celular
- script.js: menu e galeria de imagens
- assets/: imagens utilizadas no site (mantenha esta pasta)
- .nojekyll: permite servir os arquivos estáticos diretamente

## Envio ao GitHub

Extraia o ZIP no computador. Envie o conteúdo extraído ao repositório, mantendo index.html na raiz e as imagens dentro da pasta assets. Não envie apenas o ZIP nem coloque todos os arquivos dentro de outra pasta.

Configure o GitHub Pages para publicar a raiz da branch que contém esses arquivos. Não renomeie os arquivos e não adicione sufixos como [1].

Esta versão inclui a fotografia do preparo do café e a galeria: clique ou toque nas fotos para ampliar, use os botões para navegar e Fechar ou Escape para sair.

As fotografias foram aproveitadas dos materiais fornecidos; sua resolução está limitada aos arquivos originais. Telefone, endereço e avaliações são os dados fornecidos para o protótipo. Confirme os dados com o estabelecimento antes da divulgação pública.
